# RK3576 HDMI 调整页

此处归档 2026 年 11 月 16 日的板端 HDMI 调整页源码、显示改动和既有测量。调整页基于 GTK 3、X11 和板端视觉模块，可查看预览并调节相机成像和显示倍率。

- 四个 Python 文件组成调整页。systemd 文件记录 RK 板端进程及运行目录。
- 四个 patch 分别对应板端的 `native_view.py`、`pose_chart.py`、`rga_x11.cpp`、`shared_preview.py`。补丁上下文来自板端当时的源码，使用前需比对目标版本。
- 当时使用的 Rockchip Xorg modesetting 设置，需在所用驱动支持时将 `Option "FlipFB" "always"` 放入对应的 `Device` 段。现场 HDMI 去重源帧率需要重新测量。
- [延迟验证记录](./延迟验证_20261116.json)覆盖两个独立 12 秒窗口。显示源帧按相机源帧 ID 去重，记录约 60 FPS。缓冲由 8 帧调至 4 帧，FPGA 预览 DMA 首拍至 X11 提交返回的中位值由 162.1 ms 降至 94.8 ms（样本数分别为 11 和 12）。测量端点为 X11 提交返回，屏幕实际发光时间未测。

这是既有板端数据；本次整理未运行板卡、控制台或模型。

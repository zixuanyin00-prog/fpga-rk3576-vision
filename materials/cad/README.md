## 文件与版本

| 目录 | 内容 |
| --- | --- |
| [板卡支架与外壳](板卡支架与外壳/) | 试装版、FPGA 四点固定版、Blender、GLB、STL、生成脚本和 A4 纸样 |
| [板卡支架圆角底板版](板卡支架_圆角底板版/) | 独立 Blender 工程、详细结构图、四件 FDM 打印包和导出脚本 |
| [屏幕底壳可拆卸桌面支架](屏幕底壳_可拆卸桌面支架/) | 首版底壳、支架、整件与分件模型 |
| [屏幕底壳 25 mm 四周包边](屏幕底壳_25mm_四周包边/) | 连续围边、可拆前框与桌面支架 |
| [屏幕底壳 M3 铜柱安装版](屏幕底壳_M3铜柱安装版/) | 10 mm 铜柱方案、孔径试片、装配与导出记录 |
| [屏幕底壳仅整体版 STL](屏幕底壳_仅整体版_STL/) | M3 版的整件底壳、前框、左右支架与底座 |

`.blend` 可在 Blender 5.2 打开编辑。`.glb` 适合插入支持 3D 模型的 PowerPoint。`.stl` 以毫米为单位，按 100% 比例导入切片工具。每一版的装配尺寸和打印方向见所在目录说明。图中的板卡与紧固件是根据尺寸和外观建立的装配示意。屏幕底壳各版的孔位、材料和线缆间隙以对应的实物试装为准。

板卡版的 `build.py` 使用 Python 3.12、NumPy、trimesh 和 manifold3d。屏幕版可在复制出来的目录通过 `blender --background --factory-startup --python build_screen_enclosure.py` 重新导出。圆角底板版可在复制出来的目录用 `blender --background 外壳与支架_圆角底板版.blend --python export_fdm.py` 重新导出 FDM 文件。脚本会写入对应版本的文件夹。

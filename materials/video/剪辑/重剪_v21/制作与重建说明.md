# B 曲面装置整片工程

成片：`FPGA视觉系统_B曲面装置_全片_v21.mp4`。

以v19已审定剪辑为基线，片头、四章封面、ISP、小样本、PCIe/压缩、连续观测、过线触发、像素尺寸、异常留证和结尾亮点共13段图形资产重新绘制，总计48秒。全片179.8秒，1920×1080、60fps、10788帧；实战保留80.3秒。实拍来源、剪点、快慢放、旁白原词和字幕时序保留。

## 视觉与建模

方向参考[Ordinary Folk《Equilibrium》](https://www.ordinaryfolk.co/project/equilibrium)的浅色实体空间、弧面薄带与材质反差；实际几何、图形和音效由本工程代码构建，不读取案例图片或音乐。

- `geometry_b.cjs`：由用户指定的Astra、xhigh子代理负责全部三维建模；透视投影、深度缓冲、连续光照、抗锯齿和实体形状。
- `scenes_b.cjs`：图形版式、原文、连续帧关系和动作时序，调用上述几何内核。
- `render_b.cjs`：以每个输出帧的`frame/60`独立调用绘制函数，直接写入FFmpeg；不采用低帧率中间视频转60fps。图像中的历史帧保留为冻结观察记录，整体动画仍连续更新。
- `content_manifest.json`、`content_audit.json`：可见文字、旧资产出处、时长与哈希。

跨帧关联修正为一个上方摄像头、一个运动工件、三个依时间出现的图像快照。三次快照与主画面的同一轨迹时刻相对应，并用同一ID关联。删除旧B样片的门形检查站隐喻。

触发线按模型的真实投影画出，过线阈值与位置一致；JPEG和LZ77作为预览/归档的并行可选模式，和原生RGB推理分离；尺寸只表示检测框像素宽高；SD保留可选及挂载条件。

## 字幕与声音

旁白与逻辑字幕复用v19，浅底动画片段切换为深蓝字幕；跨实拍/动画的句子只改变呈现颜色，不改词句。实拍上的功能标注继续保留。恒定低音量背景音乐保留，新增低音量陶瓷短谐振和材质摩擦音效，与章节和观测时刻对齐。

## 重建

在项目根目录运行：

```powershell
python .\剪辑\重剪_v21\build_v21.py prepare
node .\剪辑\重剪_v21\render_b.cjs all
python .\剪辑\重剪_v21\build_v21.py assemble
python .\剪辑\重剪_v21\build_v21.py sound
python .\剪辑\重剪_v21\build_v21.py final
python .\剪辑\重剪_v21\verify_v21.py
```

单场重绘示例：`node .\剪辑\重剪_v21\render_b.cjs tracking_short`。仅预览静帧，在命令末尾加`--stills`。

依赖沿用项目内的`@napi-rs/canvas`、FFmpeg 7.1和本机微软雅黑/DIN等字体。没有修改应用、模型、FPGA或板端运行状态。

## 风格保留

A、B、C原始小样源码与参考说明存于相邻的`风格规范与备选`目录；A/C保留。旧B原小样不覆盖本版，旧门形只作弃用设计追溯。C整片是否另做，按`continuation_condition.json`中用户给定的北京时间条件执行。

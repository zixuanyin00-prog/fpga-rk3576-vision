# B 风格建模内核与接入规范

本文件对应 `geometry_b.cjs`。几何、材质、灯光、投影、遮挡和运动集中在此脚本；场景文字与逻辑标注由 `scenes_b.cjs` 负责。没有图片生成素材，也没有在线资源依赖。

## 视觉规范

- 浅雾蓝背景 `#cbdde9`；正文深蓝 `#183747`。主雕塑使用银白宽缎带 `#edf2f1`、鲜绿窄带 `#52c446`、浅蓝后卷带 `#6096bc`。
- 主雕塑是实体材质研究的视觉隐喻，不代表现场新增硬件。四个 `variant` 具有不同样条路径、波峰位置、宽度与扭转，不是同一圆环换色。
- 银白主带宽 164–182，绿色带宽 82–94，蓝色带宽 112–128；厚度 8–10。宽窄差异和前后留白保证轮廓层次。
- 三条带位于互相分离的深度区域。非同轴、非闭合桶壁。表面通过连续样条及扭转构造，边缘圆角属于同一实体网格。
- 面光源、正面填充、天空填充、宽高光和少量轮廓反光形成柔和棚拍材质。银白大面保持浅色，不使用黑描边或发光来伪造体积。
- 动作前 0.34–0.46 秒逐片入位，随后保持轻微连续转动。所有动画以真实秒 `t` 计算；渲染器必须逐帧传入 `frame / 60`。
- 技术场景使用简化而可信的相机、芯片、薄板与贴片电阻。电阻依据真实 `重剪_v13/sample_assets/native_3.png` 的扁平黑色主体与银端帽建模。

## 真实性边界

`tracking` 中只有一台位于工件上方的相机、一张传送面和一个连续移动的电阻。三张历史采图属于同一相机的不同时间，不是三套设备，也不是三个门或机械检查站。

`trigger` 中 `progress = 0.5` 对应物件中心真实经过 `x = 0` 的逻辑触发线。几何返回该线两端的真实投影坐标；场景层绘制虚拟标注，不增加物理门架。

相机、传送平面和芯片是讲解用简化模型，不能作为现场机械尺寸、实物设计或控制执行成功的证据。离线视频的 60 FPS 与板端新源显示 60 FPS 是不同验收项。本次未加载、切换、部署训练模型，也未操作硬件。

## 主 API

```js
const B = require('./geometry_b.cjs');
B.background(ctx);
const result = B.drawModel(ctx, 'tracking', {
  x: 72, y: 225, w: 1110, h: 548,
  t: frame / 60,
  progress: 0.5,
  quality: 1.5
});
```

| 参数 | 含义 |
| --- | --- |
| `x, y, w, h` | 当前画布内的绝对像素视口；只在此矩形内透明叠加，不清除场景背景 |
| `t` | 本场真实时间，单位秒；不量化到低帧率 |
| `progress` | `tracking` / `trigger` 物件路径进度 0–1；俯视 `resistor` 的帧内横向位置 |
| `variant` | 主雕塑 0–3 四种构图；芯片及薄板材质组合 |
| `quality` | 超采样倍数，默认 1.5；正式输出保持至少 1.5 |
| `view: 'top'` | 电阻使用固定正上方镜头，适合历史采图卡片与像素框 |
| `energy` | 主雕塑短入位动作的时长参数，默认 1 |
| `eye, target` | 可选三维相机覆盖；正常场景使用内置构图 |
| `padding` | 视口填充比例，默认 0.88 |

可用 `kind`：`hero`、`ribbon`、`camera`、`resistor`、`chip`、`plates`、`tracking`、`trigger`、`dimensions`、`alerts`。`ribbon` 是主雕塑的便捷别名。

返回：

```js
{
  landmarks: {
    object: {x, y, z},
    camera: {x, y, z},
    bounds: {x, y, w, h},
    planeCorners: [{x,y,z}, ...],
    triggerLine: [{x,y,z}, {x,y,z}]
  },
  project: worldPoint => ({x,y,z}),
  scene,
  stats
}
```

只有当前模型涉及的 landmark 才返回。`x/y` 均为绝对画布像素；`z` 为视空间深度。`bounds` 是电阻实体包围盒的真实投影，不是猜测的二维固定框。

历史采图卡片可独立创建 512×288 Canvas，并调用：

```js
B.drawModel(cardCtx, 'resistor', {
  x:0, y:0, w:512, h:288,
  t:0, view:'top', progress:observedProgress,
  quality:1.5
});
```

镜头范围固定，只有电阻位置变化；卡片应由场景层明确标识为已采帧。

## 低层接口

导出 `C`、`MAT`、`smooth`、`mix`、`createScene`、`background`、`render`、`project`、`hero` 和以下构件添加函数：

- `addRibbon`：具有真实厚度及圆角的环形截面带，可独立设置半径、宽度、角区间与截面倾角。
- `addSweep`：三维样条卷带；`points` 为中心线点列，`width` / `thickness` 为实体宽厚，`twist: [起始角, 结束角, 中段附加角]` 控制连续扭转。
- `addPlate`：尺寸为 `[宽, 高, 深]` 的圆角实体板。
- `addResistor`、`addCamera`、`addChip`：返回几何标注位置的实体构件。
- `addTube`：沿三维三次贝塞尔路径的连续圆管，采用稳定截面框架。
- `addContactShadow`：深度测试的柔和接触阴影，避免阴影覆盖到前景物体表面。

坐标 Y 向上，`position` / `rotation` 为三维数组，旋转单位为弧度；`scale` 为统一缩放。低层构件通过 `scene.objects` 统一送入 `render`，不会各自进行平均深度排序。

## 已修复的建模缺陷

1. 用真透视投影和逐像素逆深度缓冲替代旧版按多边形平均深度绘制，解决遮挡次序、曲面穿插和边面漏绘。
2. 网格连续坐标、统一外向绕序、真实圆角和端面封口；不用多边形描边遮盖拉链缝。
3. 样条曲面的法线来自两个切向方向，主宽面额外细分。高光在扭转处连续，避免大三角形造成对角亮度接缝。
4. 顶点颜色与深度均作透视校正插值；1.5 倍超采样后高质量缩小，避免阶梯轮廓。
5. 去除传送面的两条亚像素细边，消除远景锯齿。
6. `trigger` 使用不含上方相机的独立构图范围，避免无相机时平面缩得过小。
7. 废弃同轴竖直三段桶壁式主雕塑，替换为四组不同的空间样条卷带；提高银白、浅蓝和绿色面亮度。

## 可重复核验

```powershell
node '剪辑\重剪_v21\geometry_b.cjs'
node '剪辑\重剪_v21\geometry_b.cjs' --motion
```

结果写入 `geometry_qa`：12 张 1920×1080 多时点静帧、`qa_report.json`、`geometry_checks.json`，以及可选的 `geometry_motion_60fps.mp4`。

本次最后核验结果：

- 12 张静帧已目检，覆盖四种主雕塑、三时点连续观测、单电阻、相机、芯片、薄板与触发平面。
- 将主雕塑对象提交顺序完全颠倒，输出像素变化 **0**；遮挡结果不依赖对象提交次序。
- 动态检查为 1920×1080、60 FPS、6 秒、360 帧。源 RGBA 的 SHA256 全部不同，相邻重复帧 **0**。
- 单帧同时绘制主雕塑和连续观测装置，平均绘制 **29.29 ms**，P95 **31.07 ms**。这是离线生成耗时，不是播放帧率；生成的视频按真实 60 个不同画面/秒播放。
- FFmpeg 已完整解码这 360 帧，退出码 0；容器实际报告 H.264、1920×1080、60 FPS、6.00 秒。

正式整片编码、配音、字幕、13 场集成与 179.8 秒总长由主整合脚本核验，本模块的局部核验不替代整片验收。

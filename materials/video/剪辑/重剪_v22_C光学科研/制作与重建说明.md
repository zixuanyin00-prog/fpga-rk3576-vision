# C 光学科研备选全片

成片：`FPGA视觉系统_C光学科研_全片_v22.mp4`。

B为主选版本。B于北京时间2026年11月4日02:05:21完成离线成片核对，距离08:00超过3小时，因此按用户预先授权继续制作C。条件记录在相邻`重剪_v21/continuation_condition.json`。

## 内容与风格

同样替换片头、四章封面与全部技术图形，共13场、48秒。实拍、剪点、倍率、旁白词句和字幕时间保持v19基线；整片179.8秒、1080p60、10788帧，实战80.3秒。

C采用黑、暖白、朱红和黄橙，使用机械遮片、光学孔径、切角纸面、套印边与科学出版排版。它采用独立版式，不是B的换色版本；三维技术实体直接复用Astra已完成的v21几何，并由C代码转为暖色印刷质感。没有新增三维实体模型，也没有图像生成素材。

旧C小样中15/20Hz的时间步进已弃用。正式版每帧传入`frame/60`，动作连续计算，入位后保留有意的阅读停顿；不为避免静止帧而让文字不停晃动。

## 技术表达

沿用B已修正的单上方摄像头、同一工件在三帧不同位置、同ID关联；触发线投影和过线阈值一致；JPEG/LZ77是独立于原生RGB推理的可选预览/归档支路；尺寸为像素检测框；SD为可选并需启用挂载。内容清单见`content_manifest.json`与v21的`content_audit.json`。

旁白及恒定低音量背景音乐复用基线，另以程序合成短继电器、光学遮片与确认音。字幕底部始终保持深色留量。

## 重建

在项目根目录运行：

```powershell
python .\剪辑\重剪_v22_C光学科研\build_v22.py prepare
node .\剪辑\重剪_v22_C光学科研\render_c.cjs all
python .\剪辑\重剪_v22_C光学科研\build_v22.py assemble
python .\剪辑\重剪_v22_C光学科研\build_v22.py sound
python .\剪辑\重剪_v22_C光学科研\build_v22.py final
python .\剪辑\重剪_v22_C光学科研\verify_v22.py
```

单场示例：`node .\剪辑\重剪_v22_C光学科研\render_c.cjs tracking_short --stills`。

依赖项目内Canvas、FFmpeg 7.1、本机字体、v21的Astra几何与审定文案，以及v13的15张真实原生样本。没有运行设备应用或加载、部署模型。

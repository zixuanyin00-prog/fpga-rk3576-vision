## 证据来源

- ISP为现有processed RGB样本上的离线确定性再处理，使用原图及OpenCV处理结果，未制作现场采样或FPGA上板运行结果。图像不做生成式细节补造。来源、参数和算法差异保存在`evidence_isp_compression/evidence_audit.md`。
- JPEG为15张512×288 RGB888图的Pillow/libjpeg Q90、4:4:4编码测试，原始共6,635,520 B，编码共473,287 B。LZ77-16为项目已有参考编码器，输入YUYV，15帧解码与各自输入逐字节一致。

- 尺寸图来自2026-10-29真实历史模型输出，源帧448296及对应RGB哈希匹配，4个bbox据其原生坐标计算w/h，只表示像素宽高。
- 回传页来自真实PC receipt与对应文件，100条归档长度与SHA256核对匹配。没有实卡成功写入记录；按用户确认，画面只展示网口真实归档，SD以能力文字和解说呈现。
- 99.997%、1080p60、采集到HDMI小于50ms、1200件/分钟沿用之前用户明确确认的口径；本次没有重新进行这些硬件或现场性能测量。

## 编辑与重建

入口脚本`build_v23.py`管理时间线、素材处理、旁白、字幕和合成；`evidence_scenes.cjs`管理5个照片证据场景。其余B封面/章节/动画引用v21，原始素材和旧版文件均保留。

```powershell
python .\剪辑\重剪_v23_证据补强\build_v23.py prepare
python .\剪辑\重剪_v23_证据补强\build_v23.py footage
node .\剪辑\重剪_v23_证据补强\render_evidence.cjs all
python .\剪辑\重剪_v23_证据补强\build_v23.py voice
python .\剪辑\重剪_v23_证据补强\build_v23.py compose
python .\剪辑\重剪_v23_证据补强\build_v23.py assemble
python .\剪辑\重剪_v23_证据补强\build_v23.py final
python .\剪辑\重剪_v23_证据补强\verify_v23.py
```

修改来源区间、裁剪或速度时使用新的输出版本目录，避免旧片段被复用。图形渲染按源码哈希更新缓存。`visible_manifest.json`记录实际可见文字、动画时序及证据文件；三组证据目录保留原始图像、日志、测试和哈希。

本轮只修改媒体及说明文件，没有连接硬件或应用模型。

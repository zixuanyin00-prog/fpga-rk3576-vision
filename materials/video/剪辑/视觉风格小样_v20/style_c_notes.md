# C：复古光学科研片头

专业参考：[Art of the Title — The Andromeda Strain (1971)](https://www.artofthetitle.com/title/the-andromeda-strain/)。已阅读其官方条目，并查看本地参考海报。条目归纳了色块序列、信息叠印与变形，以及交错的设备哔声；配乐 Gil Mellé 把电子声音、乐器和具体声响结合。这里借鉴光学套印、色块遮片和设备节拍的视觉语言；不复用原片画面，也不沿用原片阴森低沉的情绪。

画面全部由 `style_c.cjs` 的 Canvas 几何、文字与程序颗粒直接绘制。没有 AI 生成图、背景贴图、渐变、圆角卡片、代码雨或发光网格。黑、暖白、朱红、橙黄形成印刷式套色；主体是切角检查光孔，片头与转场采用六边形快门。

时间：0–3 秒显示章节号、章节名和副题；3–4 秒光学孔径收合再打开；4–16 秒展示同一矩形工件沿连续轨道移动。5.2 / 7.4 / 9.6 秒只在实际位置留下观测刻线和对应标签，`ID 07` 始终跟随同一个工件。11.7 秒切换为“类别已确认”，稳定保持。未添加投票、预测、多模型、指标或板端结果。

输出目标是 1920×1080 / 60fps / 16 秒。构形使用章节 15Hz、机械快门与跟踪 20Hz 的离散节拍，稳定停留给文字阅读。最底部 100px 留给公共字幕。音效建议短促继电器 click、轻纸带、清亮哔声，11.7 秒用轻快双音；公共旁白与另两套保持一致。

自审：重点检查章节可读性、完整身份文字、同一工件关联，以及 1.7 / 7 / 13 秒真实 Canvas 预览。此为离线视觉样片，不涉及模型加载、部署或板端运行。

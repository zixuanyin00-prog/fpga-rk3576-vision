# 三种实际渲染的小样

每段16秒、1920×1080、60fps，均含章节03「识别与工业检测」和同一段「同一工件，连续确认」动画。三个版本的文案及观测时间保持一致，便于比较视觉与声音。

## A：动势字场

参考 [DIA / Brand New School：Johnnie Walker Keep Walking](https://www.brandnewschool.com/work/johnnie-walker-keep-walking) 的动态字体与模块化占幅，以及 [Studio Dumbar：DEMO 2022](https://studiodumbar.com/work/demo-2022) 的代码动效方法。

采用米白、黑色和少量朱红；大字字宽收放、横向字形切片、硬边遮罩将章节横线接成观测轨道。声音是干脆的短击、切纸摩擦与确认落点。源码：`style_a.cjs`。

## B：曲面装置

参考 [Ordinary Folk：Equilibrium](https://www.ordinaryfolk.co/project/equilibrium) 的弧形实体、浅色空间与材质对照。

采用浅雾蓝、绿、银白；程序生成的曲面薄板下折成为连续轨道。以投影网格、面排序、明暗和接触阴影形成实体空间，运动使用五次minimum-jerk曲线。声音是材质滑动与短玻璃谐振。源码：`style_b.cjs`。

## C：光学科研

参考 [Art of the Title：The Andromeda Strain](https://www.artofthetitle.com/title/the-andromeda-strain/) 收录的色块片头、信息叠印与设备音语言。

采用黑、暖白、朱红、橙黄；六边形孔径、机械遮片、切角构图及离散节拍。程序颗粒和套色偏移服务复古光学质感。声音是继电器式点击、纸带节拍与双音确认。源码：`style_c.cjs`。

## 制作与复用

图形全部通过Canvas逐帧绘制。音效由`make_sound.py`确定性合成。专业案例仅作参考，案例图片保存在`references`用于调研；生成画面、音轨均不读取这些参考位图或案例音乐。

`render_samples.cjs`注册本机字体并将960帧直接送入FFmpeg。三个`style_*.cjs`文件提供`draw(g,t)`和视觉、声效事件元数据，可继续扩展封面、四个章节与其他技术动画。

重建示例（在本目录）：

```powershell
node render_samples.cjs a
node render_samples.cjs b
node render_samples.cjs c
python make_sound.py
```

最终三段MP4已经合并对应立体声音效。`delivery.json`记录交付文件和时长，`style_*_manifest.json`记录源码哈希、完整文案与参考链接。

调研入口：[Motionographer](https://motionographer.com/)、[Stash](https://www.stashmedia.tv/)、[Art of the Title](https://www.artofthetitle.com/)、[Studio Dumbar](https://studiodumbar.com/work/)、[Ordinary Folk](https://www.ordinaryfolk.co/work)。

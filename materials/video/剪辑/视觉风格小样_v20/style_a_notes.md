# A · 动势字场

参考官方项目：
- https://www.brandnewschool.com/work/johnnie-walker-keep-walking
- https://studiodumbar.com/work/demo-2022

Brand New School/DIA 案例中实际可提取的是单色字场、跨屏模块比例和文字本身承担动作；Studio Dumbar 的官方案例说明创意编码扩展了字体运动的可能。此处仅转化运动原则，不复制商标、品牌字体、构图或参考画面素材。

本方案用米白、炭黑、少量朱红。章节采用接近整幅高度的 03 和两行中文大字，字宽在明确的 0.8 秒区间展开，并将字体切成六个可控横片。其后正文停留到 3 秒。3–4 秒章节画面六条横片依次滑出，直接露出连续跟踪场景，轨道同时伸展，没有空黑。

跟踪画面为单根轨道而非卡片阵列。电阻始终只有一个，ID 07 随工件移动。5.2、7.4、9.6 秒分别留下真实观测标记，先前标记保留，工件继续前进。11.7 秒替换状态文案，12.18 秒后固定确认状态与工件位置，稳定保持至片尾。底部 980–1080 像素不放信息，可添加后续字幕。

全部可见视觉由 Canvas 字体、矩形、线条和裁切生成；没有渐变、圆角卡片、外部位图或图标库。只呈现规定内容，不增加投票、预测、两个模型、性能指标或学校队名。

已实际输出并逐张查看 0.3、1.7、3.5、7、13 秒 PNG；核对中文字体、切片入场、转场期间无空黑、单个工件及 ID 关联、三次真实观测和确认末态。检查后收窄章节数字，避免 03 的右边被裁切。

声效事件见 style_a.cjs 的 meta.sound_events，使用干短的字形落位、纸片扫动和相同观测音；避开游戏式连续提示音。最终混音由主任务统一，旁白沿用已有内容。

# 控制台与 GPIO 后续源码

2026 年 11 月 17 日的板端 GPIO 输出模块，以及当前工作目录里配套的 VisionTrainer 界面、纯预览、全局运行选项、控制台流程和相关测试。按原仓库相对路径放置，便于和仓库根目录的发布基线对照。
